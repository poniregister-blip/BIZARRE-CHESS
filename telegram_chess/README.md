# CHESS: THE WORLD — Telegram Edition

## Запуск
1. Создайте бота в @BotFather (/newbot). Включите inline mode (/setinline).
2. Разместите проект на Node.js 22+ хостинге с HTTPS и постоянным диском. В каталоге проекта выполните npm install и npm test.
3. Задайте переменные окружения BOT_TOKEN (секретный токен), BOT_USERNAME (без @), APP_SHORT_NAME (например chess), PUBLIC_URL (HTTPS URL приложения без завершающего /), WEBHOOK_SECRET (случайная строка из букв и цифр), DB_PATH (путь на постоянном диске, например /data/games.db), PORT (по требованиям хостинга).
4. Запустите npm start. В @BotFather создайте Mini App (/newapp) с тем же коротким именем и PUBLIC_URL.
5. Зарегистрируйте webhook из терминала, где заданы переменные окружения:

```sh
curl -X POST "https://api.telegram.org/bot${BOT_TOKEN}/setWebhook" --data-urlencode "url=${PUBLIC_URL}/telegram/${WEBHOOK_SECRET}" --data-urlencode "secret_token=${WEBHOOK_SECRET}"
```

6. Оба игрока должны открыть личный чат с ботом и нажать Start, чтобы бот мог отправлять уведомления. Откройте игру, выберите режим, отправьте ссылку другу через кнопку «Пригласить». Друг открывает ссылку и занимает второе место. Приглашение можно отправить в личную переписку. Уведомления приходят в личный чат с ботом, а не автоматически в личную переписку двух людей (ограничение Telegram).

## Реализация
Сервер проверяет подпись Telegram initData, участников, очередь хода и ревизию партии. SQLite хранит партии и результаты. Клиент опрашивает сервер каждые 1.5 секунды. Реванш создаёт приглашение конкретному сопернику. Реестр stands в server.js — начальная точка расширения; для новых способностей с иными переходами состояния потребуется расширить обработчики и интерфейс. В классике поддерживаются автоматические ничьи по 75 ходам и пятикратному повторению; заявления ничьей по 50 ходам и троекратному повторению пока не реализованы. В режиме стендов правила ничьей адаптированы. Синтезированный звук и SVG-анимация из v1.3; звук может требовать первого касания экрана. Ссылки обычных приглашений доступны любому получателю до занятия второго места. Один экземпляр сервера, резервное копирование SQLite и постоянный диск обязательны для сохранения партий.

Проверка: node --check и perft глубины 4. Реальная интеграция Telegram, установка npm-зависимостей и браузерное тестирование не выполнены в среде разработки. Перед публичным запуском проверьте две учётные записи, уведомления, восстановление после перезапуска и реванш.
